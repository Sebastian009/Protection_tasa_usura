01 · Metodología

¿Cómo se calcula
la tasa de usura?

TIBC Proyectada

Promedio ponderado de la tasa efectiva de los desembolsos, ajustado por el factor compuesto de cada operación.

TIBC_p = Σ(Tasa × Monto × Factor)
─────────────────────────
Σ(Monto × Factor)
Usura Proyectada

La tasa de usura es 1.5 veces la TIBC, tanto en la proyección como en el valor certificado por la SFC.

Usura_p = TIBC_p × 1.5
Usura_r = TIBC_r × 1.5

ΔTIBC = TIBC_p − TIBC_r
Factor Compuesto

Producto de cinco factores individuales. Si un factor no aplica se trata como neutro (= 1).

factor_a = f1 × f2 × f3 × f4 × f5

fᵢ = 1 si no hay factor asignado
Fuente TIBC Real

La TIBC certificada se consulta automáticamente desde la API abierta de datos.gov.co en cada ejecución.

# Carga vectorizada de factores — DRY
factores <- lapply(seq_along(COLS_JOIN_FACTORES), function(i) {
  read_excel(RUTA_FACTORES, sheet = i) |> setDT()
})

for (i in seq_along(factores)) {
  col_join  <- COLS_JOIN_FACTORES[i]
  col_nueva <- paste0("factor_", i)
  bd[factores[[i]], on = (col_join), (col_nueva) := i.factor]
}

# Factor compuesto — NA tratado como neutro
bd[, factor_a := fcoalesce(factor_1, 1) *
               fcoalesce(factor_2, 1) *
               fcoalesce(factor_3, 1) *
               fcoalesce(factor_4, 1) *
               fcoalesce(factor_5, 1)]

# TIBC proyectada por corte
calculos <- bd[, .(
  TIBC_p = sum(tasa_efectiva * montos * factor_a, na.rm = TRUE) /
            sum(montos * factor_a,          na.rm = TRUE)
), by = .(corte)]

calculos[, USURA_p := TIBC_p * 1.5]
